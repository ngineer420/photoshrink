About this image cropper

Once your photo loads, a crop box appears over it — drag the middle to move it, drag any corner handle to resize it. Pick a fixed aspect ratio if you need the result to fit a specific frame (square avatars, 16:9 thumbnails, 4:3 prints), or leave it on Free for full control. The download uses the image's real pixel resolution, not the (possibly scaled-down) preview, so the cropped file is never blurrier than the source deserves.

How to crop an image

  1. Drop, browse to, or paste a photo into the box above.
  2. Drag the crop box into place, and drag a corner to resize it.
  3. Pick an aspect-ratio preset if you need an exact shape.
  4. Click Download to save just the selected area.

FAQ

Will the cropped image be blurry?

No — the crop is computed against the original full-resolution image, not the on-screen preview. What you see is a scaled-down preview for convenience only.

Can I crop to a specific aspect ratio?

Yes — use the 1:1, 4:3, 16:9, or 3:2 presets, or "Free" for any shape you draw by hand.

What format is the cropped download?

By default it keeps the original format. Change it in the Output format dropdown, or use the dedicated converter afterward.
