          Ten image tools, zero uploads

          PhotoShrink runs every tool locally in your browser using the HTML Canvas API — the same engine browsers use to draw web pages. When you drop in a photo, it's decoded and processed entirely on your device; the pixels never touch a network request. That means no upload wait, no file-size limit imposed by a server, and no copy of your photos sitting on someone else's disk.

          Working to a hard file-size limit? The compressor can search for it: Compress image to 100KB, Compress image to 200KB, Compress image to 500KB, Compress image to 1MB, Compress image for email, Compress image for Discord.

          Prefer a dedicated page for one tool? Each one also lives on its own: Resize, Compress, Crop, Convert, Rotate & Flip, Image to Base64, Favicon Generator, EXIF Viewer & Metadata Stripper, Redact a Screenshot, and Blur an Image.
